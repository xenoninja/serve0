# Static Page Previews

This context covers viewing static HTML mockups on a remote machine during development and design review.

## Language

**Preview page**:
The HTML document selected for viewing in a browser.
_Avoid_: Entry page, mockup file

**Preview asset**:
A local companion file used by a preview page, such as a stylesheet, script, image, or font.

**Preview directory**:
The directory containing the preview page, including the subdirectories where its preview assets may reside.
_Avoid_: Project root, working directory
